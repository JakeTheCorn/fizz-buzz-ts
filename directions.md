# FizzBuzz Directions

Follow these steps to solve the FizzBuzz problem:

1. **Print numbers from 1 to 100**  
  Loop through the numbers 1 to 100, inclusive.

2. **For multiples of 3**  
  If a number is divisible by 3, print `"Fizz"` instead of the number.

3. **For multiples of 5**  
  If a number is divisible by 5, print `"Buzz"` instead of the number.

4. **For multiples of both 3 and 5**  
  If a number is divisible by both 3 and 5, print `"FizzBuzz"` instead of the number.

5. **For all other numbers**  
  Print the number itself.

**Example Output:**
```
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
...
```
